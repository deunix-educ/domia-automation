    Décisions d'architecture (ADR)¶

    Format : 0000-template.md (contexte, options, décision, conséquences). La version de référence des ADR est l'anglais lorsqu'il existe ; les documents qui les citent ont une version anglaise. Un ADR remplacé n'est pas supprimé : son statut renvoie vers celui qui le remplace.
