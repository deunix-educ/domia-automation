# DomiNet

Domotique et vidéosurveillance auto-hébergées, réécrites en Rust : appareils Zigbee2MQTT, caméras IP (ONVIF, WebRTC, enregistrements, détection de mouvement et d'objets), énergie, automations, scènes, alertes, messagerie, Android, observabilité (Prometheus, Grafana) et sauvegardes.
