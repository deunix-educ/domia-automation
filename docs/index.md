# DomiNet

Self-hosted home automation and video surveillance, rewritten in Rust: Zigbee2MQTT devices, IP cameras (ONVIF, WebRTC, recordings, motion and object detection), energy, automations, scenes, alerts, messaging, Android, observability (Prometheus, Grafana) and backups.
