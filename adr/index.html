    Architecture decision records (ADR)¶

    Format: 0000-template.md (context, options, decision, consequences). A superseded record is not deleted: its status points to the one that replaces it. Every record exists in English (the reference) and in French (*.fr.md). For a reading by theme, start with Decisions by theme.

    ADR Subject Status
    0001 Global architecture (workspace, single binary, x86-64-v2 target) accepted
    0002 IoT storage: ReductStore (raw) + PostgreSQL (aggregates) accepted
    0003 Video decoding: ffmpeg subprocess behind a FrameSource trait accepted
    0004 Authentication and sessions (own store on sqlx 0.9) accepted
    0005 MQTT client: rumqttc accepted
    0006 Automation scripts: sandboxed Rhai host accepted
    0007 Front end: Leptos SSR + hydration, WebSocket, Fluent i18n accepted
    0008 ONVIF: minimal hand-written SOAP client accepted
    0009 Object detection: YOLOv8n through ort accepted (reservations)
    0010 Camera live view: WHEP client in Rust/WASM towards MediaMTX accepted
    0011 Encryption of sensitive values at rest (AES-256-GCM) accepted
    0012 Interface: Leptos server functions and three crates accepted
    0013 CI on a self-hosted runner partly replaced by 0015
    0014 Generic CRUD component for administration pages accepted
    0015 Local gate (pre-push hook) instead of automatic CI accepted
    0016 Nonce-based CSP and the base WebSocket hub accepted
    0017 Docker image with cargo-leptos and end-to-end tests on the image accepted
    0018 Dashboard schema: overlap exclusion, references without foreign keys accepted
    0019 Multiplexed WebSocket protocol: typed topics, last state kept accepted
    0020 System statistics: sysinfo, published as the last state of the system topic accepted
    0021 Page render guard: abandon and retry a frozen render (Leptos 0.8.23 defect) accepted (workaround)
    0022 Dashboard read view: class-based placement, sanitised HTML, restricted Grafana iframes accepted
    0023 Dashboard editing: administrators only, pointer drag, conditional-field form accepted
    0024 Browser end-to-end tests: stay on Marionette/Firefox accepted
    0025 Device schema: replaced state, per-second history, images in the database accepted
    0026 Supervised MQTT client: immediate or refused publications, re-subscribe on every connection accepted
    0027 Zigbee2MQTT ingestion: same result as the reference implementation, replayed on recorded sessions accepted
    0028 Dynamic MQTT sources, non-blocking raw ReductStore archive, history retention accepted
    0029 Validated commands, device pages and images, Grafana dashboard as a file accepted
    0030 Supervised weather and SolarMax publishers; protocol checked against reference vectors, inverter never contacted accepted
    0031 Scene, automation, alert and energy schema: reference JSON shape, strong types, deliberate deviations accepted
    0032 Automation engine: single queue, useful events only, batched states always seen, anti-loop 30/min accepted
    0033 Scheduler: scheduler role, no catch-up, cron semantics of the reference, solar computation checked against ephem accepted
    0034 Rhai scripts: all or nothing, missing key = (), muted source code, other-language code refused, dry run accepted
    0035 Alerts: cycle of the reference with its quirks (checked on 2,030 evaluations and 8 scenarios), Notifier port, alerts topic accepted
    0036 Energy balance: same computation as the reference (13 identical days), local day, server-side SVG, seed-energy / aggregate-energy accepted
    0037 Android relay and messaging: hashed token, sms_outbox queue (acks), call log, send states accepted
    0038 Delivery channels: lettre (mandatory STARTTLS, plaintext credentials refused off loopback), checked Free Mobile, fake servers, notify-test accepted
    0039 Android relay server side: exact endpoint, one connection per device, 30/90 s heartbeat, 60 s acks, android:<id> topic accepted
    0040 Android pages: per-account rights, token shown once, live reread, SMS send state, simulated phone for end-to-end tests accepted
    0041 Messaging: asynchronous background sending, live per-recipient statuses (message:<id>), rights, resume after restart accepted
    0042 Alerts and automation notifications on real channels: the rule's three channels, failure isolation, notified after the attempt accepted
    0043 Surveillance schema: seven tables, 32-hex public identifier, encrypted secrets, ports per aggregate accepted
    0044 MediaMTX client (REST only, replace, managed paths = 32 hex), camera service (encrypted secrets, non-blocking MediaMTX failure), rights accepted
    0045 ONVIF (client, service addresses, masked secrets), discovery by LISTEN/NOTIFY between the discovery and web roles, add by address accepted
    0046 Camera live view: Rust/WASM WHEP player, reconnection by getStats, no-H.264 message, host-adapted WHEP address, connect-src accepted
    0047 ONVIF PTZ (reference protocol, automatic stop, presets without orphans), four day/night methods behind NightControl, administrator rights accepted
    0048 FrameSource (one supervised ffmpeg per camera, JPEG), video role, last frame on disk, capped indexed snapshots accepted
    0049 Recording by MediaMTX (fMP4), scan of finished segments, ReductStore archive with labels, replay with Range, manual recording accepted
    0050 Motion (reference algorithm in pure Rust, OpenCV parity measured), sliding window, YOLO through ort (17/17 parity), model not committed (make fetch-model), events page accepted
    0051 Prometheus metrics: separate /metrics listener (METRICS_ADDR), bounded labels accepted
    0052 Prometheus and Grafana alert rules in the database, atomic provisioning files, non-fatal reload, seed only on an empty table accepted
    0053 Prometheus alert relay (state machine), Grafana dashboards, checks by execution and by real services accepted
    0054 Backups: gzipped pg_dump + ReductStore volume archive, SHA-256 sums, single-transaction restore, retention, scheduled, measured accepted
    0055 Compose: 8-service base + dev/prod/demo overlays, pinned images, dominet healthcheck probe, shared volumes accepted (anonymous LAN listener replaced by 0057)
    0056 MkDocs documentation built into the image, served on /docs/ behind the login (DOCS_ROOT) accepted
    0057 Authenticated MQTT: one listener with a password, named accounts per client, rights per topic (make prod-mqtt-user) accepted
    0058 MCP server built into the binary: pinned rmcp, session-less HTTP, dominet-mcp crate, script code in the administration scope accepted
    0059 MCP access tokens: hashed, scoped, revocable, mandatory expiry, audit trail accepted
    0060 Local assistant: llama-server, Qwen3 8B and 14B, bench measurements accepted
    0061 Prometheus and Grafana alerts in the alerts page: read-only, one badge accepted
    0062 Published multi-architecture images, local build as the fallback accepted
    0063 arm64 and Raspberry Pi 5: best-effort support with explicit test status accepted

    Decisions taken outside ADRs: languages, pinned toolchain, dark theme only, migrations by a separate command.
